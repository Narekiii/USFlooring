# Typography

Use a refined combination of:

* **Manrope**, **Inter**, or **DM Sans** for navigation, buttons, body text, forms, and practical information
* **Cormorant Garamond**, **Libre Baskerville**, or **Lora** selectively for major editorial-style headlines

The serif font should add heritage and craftsmanship, but it must not make the website feel traditional or outdated.

Typography requirements:

* Large, confident headlines
* Clear visual hierarchy
* Comfortable line spacing
* Short paragraph widths
* Highly readable body text
* Strong but restrained use of uppercase labels
* No decorative script fonts
* No fake handwritten fonts
* No excessively thin text
